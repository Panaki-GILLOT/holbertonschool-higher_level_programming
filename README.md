# holbertonschool-higher_level_programming

## Description

This repository contains Python projects completed as part of the Holberton School curriculum. It covers higher-level programming concepts including object-relational mapping, serialization, and RESTful API development.

## Projects

| Directory | Description |
|-----------|-------------|
| [python-object_relational_mapping](python-object_relational_mapping/) | Using SQLAlchemy ORM to interact with MySQL databases — querying, inserting, updating, and deleting records |
| [python-serialization](python-serialization/) | Serializing and deserializing Python objects using JSON, CSV, XML, and pickle |
| [restful-api](restful-api/) | Building and consuming RESTful APIs using `requests`, `http.server`, and Flask with authentication |

## Requirements

- Python 3.x
- MySQL (for ORM project)
- See each project's README for specific dependencies
